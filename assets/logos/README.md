# Technology logos

These local SVGs are embedded into the generated profile stack. Original paths
are preserved; monochrome Simple Icons marks use colors that remain visible on
the dark background. Next.js sits on a light disc for contrast.

- JavaScript through TensorFlow: [Devicon](https://github.com/devicons/devicon), MIT. See `devicon-LICENSE.txt`.
- Hugging Face, LangChain, Ollama: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0. See `simple-icons-LICENSE.txt`.

`sources.json` records exact upstream commit URLs. Brand names and logos belong
to their respective owners. Regeneration uses these files and requires no network.
